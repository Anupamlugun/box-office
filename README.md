# 🎬 BoxOfIcee — Movie & TV Show Explorer

> A sleek and interactive **React** app where users can search for movies, TV shows, and actors, and mark their favorites with a "Star" or "Like" action. Built for performance, simplicity, and extensibility.

---

## 📌 Overview

**BoxOfIcee** is your personalized entertainment lookup app.

✅ Key Features:
- 🔍 Search movies, TV shows, and actors in real-time  
- ⭐ Star (favorite) your favorite content  
- ❤️ Like or save actors and shows for later viewing  
- 📱 Fully responsive UI for mobile, tablet, and desktop  
- ⚙️ Easily extendable to support user profiles or watchlists

---

## ⚙️ Tech Stack

| Layer         | Technology                     |
|---------------|-------------------------------|
| **Frontend**  | React.js (Create React App)   |
| **Styling**   | CSS Modules / Plain CSS       |
| **State**     | React useState + useEffect    |
| **Search API**| TVMaze API                   |
| **Dev Tools** | ESLint, Prettier              |
